# Listening Room covers

Add final square playlist artwork in this directory, preferably as optimized `.webp` or `.avif` files around 600 × 600 pixels.

Then update each `cover` value in `/listening-room.js`, for example:

```js
cover: "assets/listening-room/covers/late-night-drive.webp"
```

Spotify playlist URLs are configured in the same record object through `spotifyUrl`.
